-- Квадраты:
*Зеленый - диск без разделов, готов к записи.
*Желтый - диск с разделами, очищаем через DP DEFAULT. 
  Если не очищаются, пробуем DP RESCAN.
  Разделы очищаются на тех дисках где установлена галочка (на диске 0 по умолчанию нет галочки)
*Красный - не подключен / отключен.
*Серый - диск занят (тестируется/очищаются разделы/запрашивает смарт)
*Оранжевый - диск с ошибкой (CRC или I/O)
*Фиолетовый - диск ушел в сон либо шпиндель остановлен (при подключении SAS со слетевшим транслятором (1sec) отображается фиолетовый)

-- Кнопки:
*DP Default / DP Rescan - обычный очистка разделов и с пересканированием наличия дисков.
*Victoria (open) - открывает викторию для всех подключенных дисков. 
*Victoria (write, read) - запускает запись или чтение на каждом диске где установлена галочка(виктория должна быть открыта)
*Victoria (W-R-V) - запускает полный цикл Запись - Чтение - Верификация. Статус отображается напротив каждого диска с текущим тестом (прим. (R) 23.5%)
*Get SMART (smartctl) - использует утилиту smartctl для доступа к основным смарт аттрибутам (часы, переназначенные, current pending, uncorrectable, UltraDMA CRC)
  У SAS дисков считывает Log Sense (Uncorrectable Write/Read/Verify) и часы. Если на диске есть смарт ошибки, отобразит ASC/ASCQ ошибки и текст будет красным.
  При последующий нажатиях Get SMART, каждое изменение смарта (лучше/хуже) будет записываться в [sm_cache].
  На каждом диске в строке его названия можно кликнуть ПКМ и выполнить нужное действие только для одного диска. (Сlear, Send sleep, COPY, SMART)
*Sleep (SCSI) - отправляет SCSI команду для остановки шпинделя диска. SATA диски засыпают быстро, SAS - чуть дольше.
